OLMo signal-production replay

Scope
The package contains the new results, compact inputs, exact source snapshots,
scripts, acquisition receipts and independent audit. It excludes the three
large L1 MLP tensors (192 MiB total). No full model or later-layer computation
is included. Stored-array audit is not an independent pretrained-model replay.

Offline compact audit, no network required
1. Install/use Python with NumPy. Matplotlib is needed only to rebuild the figure.
2. From this package directory run:
   OPENBLAS_NUM_THREADS=2 python3 audit_compact.py
   OPENBLAS_NUM_THREADS=2 python3 audit_historical_paths.py
3. Expected compact result: all_checks_pass true, raw coordinate8041 bound
   0.16032984931200406. Historical controls have exact pulse/factor closure.

Complete bounded L1 replay
The tensors originally acquired are identified by exact official revision,
shape, byte range and SHA256 in acquisition_plan.json and tensors/*.receipt.json.
They are standard little-endian FP32 matrices with no custom code execution.

If those tensor bytes are already available, place the three files named
gate_proj.f32, up_proj.f32 and down_proj.f32 under tensors/ alongside receipts.
If a new 201,326,592-byte acquisition is authorized, acquire_mlp1.py downloads
only those three pinned official byte ranges. It does not download a whole
checkpoint. Do not invoke it when network acquisition is not authorized.

Then run sequentially:
   OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 python3 analyze_mlp1.py
   OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 python3 intervene_geometry.py
   OPENBLAS_NUM_THREADS=2 python3 audit_historical_paths.py
   OPENBLAS_NUM_THREADS=2 python3 audit_compact.py
   OPENBLAS_NUM_THREADS=2 python3 plot_signal.py

The scripts use packaged inputs/olmo_training_origins by default. Set
OLMO_SOURCE_ROOT to a complete original recovered evidence directory to use
that copy instead. No original evidence file is overwritten. Results under
this package's results/ are regenerated by the analysis commands.

Full-matrix validation
All selected cached rows must match the new matrices bitwise. Known selected
contributions must match at scaled error below 1e-4. Reconstructed normalized
states must differ by less than 2e-5. Direct non-1710 projection versus dominant
subtraction is explicitly checked; the stable direct result is reported.

Independent review
independent_audit/ contains a separate FP64 implementation and findings. Those
review scripts retain the original execution paths for provenance; numerical
results and final artifact hashes are saved separately. They are distinct from
the portable compact consistency audit. Their scope is still bounded L1 replay,
not native FP16/CUDA or full-model behavioral replication.

Key result files
- source_decomposition.csv: incoming, primary and alternate axis writes.
- alternate_writers_top20.csv: per-state ranked alternate writers.
- cancellation.csv: signed positive/negative sums, including source 187.
- alternate_writer_interventions.csv: whole-column selected-neuron interventions.
- h14_nonprimary_component_swaps.csv: incoming residual versus other-MLP donors.
- h14_factorial.csv: primary gate/up donor factorial.
- historical_h14_interactions.csv: 28-case component factorial interactions.
- historical_h12_summary.json: separate empty-history pathway evidence.
- mlp1_replay.npz: all 21 states, all 8192 neuron activations/writes and output vectors.
- signal_production.png/pdf: a visual summary of the five source-token cases.

Interpretation limits
All new writer sets were chosen after inspecting these states. No held-out
generalization or minimum-circuit claim follows. Geometry improvement is not
perplexity rescue. Scalar-edge deletion is not deletion of an entire output row.
The 8041 bound is raw-coordinate only, not whole-vector or downstream impact.
