# U1: do size and normalization geometry explain H14 donor swaps?
Prespecified contrast before any new directional treatments. Reuse the eight G1 non-code files, distance 24 only, including the coreutils miss. Goals: distinguish an H14 donor direction from a comparable-sized write in the same head's own output subspace; test whether other texts provide a transferable direction. No claim of unseen inputs or universal direction. Unchanged inputs and exact H14 swaps must replay G1's activation and KL within 1e-10. Original and prior-newline worlds receive source-position-only head edits of opposite sign. All comparisons use each patched world's own unlesioned reference for the scalar lesion.

Let W be H14's block of layer-0 output projection. Thin QR W=QR allows a change in 128-dimensional H14 space to be expressed in orthonormal output coordinates Q at the source position. For each file, use the true donor difference v=R(h_orig−h_nl). Split v into its projection onto the span of Q^T*ones, Q^T*x_orig and Q^T*x_nl (x is pre-MLP layer-0 residual) and tangent remainder t. Fix the projected coordinates; vary only direction of t at fixed length. Controls therefore match v's output norm, mean change, and projections on each recipient, hence idealized residual mean and norm, in both directions on that pair. This does NOT match the value-head input norm; the controlled quantities are the effective write and the geometry entering normalization, measured after actual FP16 execution. Generate 8 tangent controls using Gaussian vectors in 128-dimensional output coordinates, seeded PCG64(20261117+document index), projected and normalized. Separately use all 7 other documents' true H14 differences as tangent direction donors, projected into the same target-file tangent space and scaled. No outcome-dependent selection. Each control gets the target pair's natural radial coordinates and norm; not a blind universal intervention. If true tangent norm <10% of total norm or candidate norm vanishes, mark inconclusive, not positive. No search over random seeds or distances.

Check each realized perturbed pre-MLP residual against true swap for target: edit-norm discrepancy <=2% of true norm; difference in mean * sqrt(2048), and difference in projection onto unit normalized centered recipient, each <=2% of true edit norm. Two legs. Nonsource activations, causal prefix logits and identity donor unchanged. Keep all values if failures; a file not technically qualified cannot pass any screen.

Primary direction specificity per file: true intervention transfers >=0.5 of the signed z contrast on both legs AND exceeds the median of the eight randomized directions by >=0.25 contrast on both legs. Claim bounded conditional specificity if >=6/8 files pass, at least two of each stratum. Report distribution, not just screens. Secondary transport: within each file, a foreign donor succeeds when on *both legs* its signed fractional z transfer is >=0.5 AND within 0.25 of the true donor, restoration yields focal KL >=max(0.25,0.5*original KL) and suppression yields focal KL <0.01. At least four of the seven foreign donors must succeed to pass a file. Claim bounded transport only if >=6/8 files pass and >=2 of each stratum. Score all individual random/cross donor scalar KLs too, to separate z and behavior; these are not language-task successes, independence statements or additive mediation. No claims of geometry sufficient if the random screen fails. Same offline bounded GPU admission and guard. Stop on errors, preserve partial results.
