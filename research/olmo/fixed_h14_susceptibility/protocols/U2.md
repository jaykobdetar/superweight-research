# U2: blind transferable H14 template versus fixed equal-write-length controls
U1 conditioned on both recipient residuals: their difference itself can contain the H14 donor contrast. In five of eight files this left <10% of the true vector norm free. Do not interpret that as a clean test of magnitude versus direction. This separate study estimates a single fixed vector from the original eight Python files only, then freezes it before evaluation on eight new non-code files (four upstream READMEs bc/gawk/grep/wget, four FAQs Ubuntu fonts/sed/BPF/xz). No tuning, fitting to the evaluation files, paid resources or changes to model weights. Fixed tokenizer selection rule from G1 (first qualifying rendered paragraph boundary, same file hashes and lengths). Evaluation uses distance 24 only, not observed new outcomes. Per-file results including failures reported. Source at position 32; same 32 subsequent logits.

Training computes mean of the eight 128-dimensional true H14 head-context differences (original minus earlier-newline at position 8) coordinatewise, in FP64. Verify training clean z against H1 and hash/store the resulting vector before doing any model forward on evaluation files. No evaluation geometry, labels, activation or doses enter this vector. For controls generate eight fixed isotropic Gaussian directions in the orthonormal 128-dimensional column-space coordinates of the H14 output projection (QR with positive R diagonal, PCG64 seed 20261118); use R inverse to map to the head, scaling each to the same post-projection norm as the fixed template. Record vectors and hashes before evaluation. Do not fit the vectors to either recipient residual, or use target donors for fixed interventions. A native two-way true target donor swap is a separate positive control, never a source of template calibration. All three kinds of edits are at the source query only and preserve logits before that query. Match realized pre-MLP edit norms for each random control vs template to within 2% on each leg; since direction can change radial projection, this test distinguishes direction from write size alone, not from radial geometry. Check native self-swap exact, native positions unaffected, finite outputs. Compare each scalar lesion with its own patched but unlesioned world, not logits of a different input.

Primary target per file for the frozen template: in both legs transfer at least 0.5 of its signed native z difference AND beat median of 8 equal-write-length randomized controls by >=0.25 signed fraction; restored focal KL in prior-newline recipient >=max(0.25, 0.5*original focal KL); reciprocal suppressed focal KL in original recipient <0.01. Require nondegenerate native z contrast >=1e-8 and technically qualified controls. Freeze separate same-head oracle screen: both legs z fractions >=0.5 and both corresponding KL limits pass. Require >=6/8 template hits AND >=2/4 per stratum for bounded transfer; compare all z and KL quantities to oracle. If the frozen static vector fails, do not refit to these eight examples. If it works, applicability is limited to this model, intervention and rendered source selection; it is not a semantic task or discovery of an exact universal neuron. Existing resource guards apply.
