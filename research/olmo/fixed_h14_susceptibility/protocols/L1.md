# L1: genuinely new literary holdout, no refitting
This design is frozen before any new evaluation forward. Run the UNCHANGED 128-dimensional template from eight code examples, with the same eight frozen write-length-matched control directions and the same N1 (natural-history) per-query gates. A fresh, hashed public-domain NLTK Gutenberg release, official index SHA256 2d3c3ab548c653944310f37f536443ec85d0a0ad855fcae217a0c9efdce2d611. Eight distinct authors and texts; four prose: Austen (Emma), Carroll (Alice), Melville (Moby-Dick), Chesterton (Thursday); four verse/drama: Blake (Poems), Milton (Paradise Lost), Shakespeare (Hamlet), Whitman (Leaves). These are newly used texts for this intervention, not a claim of absence from pretraining. No retrieval or synthesis during inference. Do not distribute the source text in the summary.

Use the exact original line breaks and tokenization after collapsing only line-ending representation CRLF/CR to LF, Latin-1 as in historical NLTK Gutenberg. No soft-wrap reflow. In each work, three anchors at floor(20%,50%,80% of token length); choose FIRST qualifying 71-token contiguous window from the subsequent 2% of book tokens for each anchor. Source at position32, preceding natural ID187 at distance4..24 inclusive (nearest raw ID187), nearby alphabetic-token control first among slots 1..4 without intervening LF, >=12 alphabetic word segments in ±32 slots. No overlapping windows or duplicate token arrays; count a missing anchor as failure without replacement. No selection by model score or activation. Hash archive, included member, ID array, offsets and frozen controls. Verify panel independently before inference. No earlier token substitution. At q native newline and native nearby word, use untouched input; matched additional q-only word substitution keeps identical prefix/position/suffix apart from that one token. All scalar KLs refer to the untouched vs focal-lesioned versions of THAT patched world, scored at next 32 logit positions, not to predictions of different texts.

Frozen per-query N1 gates: true H14 intervention increases -z by >=100 and >=100 over random-median activation change; patched scalar KL(clean||focal)>=0.25 nat, >=native KL+0.10 and >=median random KL+0.10. All eight actual control write lengths within 2% of template; prefix logits and self-swap identity hold exactly. Report z gate and functional gate separately, especially word controls. Per-window natural success = qualifying newline hit; specificity = newline hit and neither word control has a joint hit. Per-work success requires >=2/3 window hits; require >=6/8 works and >=2/4 of both strata for each respective headline. To guard against interpreting weaker activation thresholds as behavioral silence, report how many word controls pass the KL-only gate independently. Numerators over 24 windows as fixed, not over variable counts; do not treat scored tokens/windows as independent books. Expand per-work counts and outcome ranges; do not adjust protocol from these results.

One local guarded run, never overwrite a partial or previous attempt. Archive one overall source inventory and per-example results. Network was used only to obtain the 4.25 MB data archive. No training, external compute or checkpoint download. An additional checkpoint is out of scope unless separately validated for H14 head/coordinate correspondence, tokenizer, precision and training provenance.
