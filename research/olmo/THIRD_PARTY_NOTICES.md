# Third-party materials and external inputs

The research documents do not relicense third-party material or create a license for the rest of this repository.

- OLMo model excerpts, tokenizer artifacts and OLMo code retain their source terms. The official [OLMo-1B-0724 model card](https://huggingface.co/allenai/OLMo-1B-0724-hf) identifies the code and model as Apache-2.0. The small included weight/optimizer slices are not a complete checkpoint. See the [Apache-2.0 text](licenses/Apache-2.0.txt), pinned revisions and per-slice receipts.
- Included Hugging Face Transformers reference files retain their original copyright/license headers and are reference text, not automatically imported acquisition code. Apache-2.0 applies to these source files; exact versioned filenames are retained.
- Native metadata and source extracts retain their original provenance and notices. Public source code copied in the optimizer package has its accompanying license. No ownership of upstream work is claimed.
- Natural input corpora are external dependencies, not part of this publication. Reproduction requiring them must acquire the exact sources under their applicable terms. [WikiText](https://huggingface.co/datasets/Salesforce/wikitext) identifies CC-BY-SA-3.0 and GFDL; Project Gutenberg book records and the pinned PyTorch source repository supply their own terms. Input hashes and dataset/source URLs identify the original inputs without redistributing their full texts.
- The developmental study's four constructed prose panels and synthetic validation prompts are experimental stimuli, distinct from natural-corpus excerpts.

The publication export omits reconstructable natural-corpus token arrays and decoded excerpts. Numerical losses, aggregate classifications and identity hashes are retained. Archived private delivery packages may have had different input contents; their original manifests are historical evidence, while the publication manifest describes this export.
