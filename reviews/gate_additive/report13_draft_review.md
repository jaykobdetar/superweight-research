## Primary-source checks

- [Sun et al., Massive Activations, §§4.2–4.3 and Appendix B.4](https://arxiv.org/html/2402.17762v2) supports the existing implicit/explicit attention-bias work. Appendix B.4 explicitly tests zero synthetic K/V vectors (Eq. 6), extra Q/K dimensions (Eq. 7), and a constant value update (Eq. 8); those alternatives did not remove massive activations in that training experiment. The draft claims that these alternatives were studied, not that zero-value replacement universally works, which is correct.
- [Fu et al., §3.1 and Appendix B.2](https://arxiv.org/html/2602.01203v1) gives the source-allocation decomposition and the sigmoid of non-source log-sum-exp minus source score. This is direct prior art for that algebra and gating interpretation. Approximate native zero values and deliberately zero synthetic values must not be conflated; the draft avoids a universal negligible-impact claim.
- [Qiu et al., §2.2](https://arxiv.org/html/2505.06708v1) studies explicit query-dependent gates after attention, including head-specific scalar gating. This supports the draft's narrow credit to prior explicit query/head gating.
- [Ran-Milo et al., abstract and Appendix A.2](https://arxiv.org/html/2604.14722v1) identifies learned query bias, early positional computation and key projection in GPT-2; Appendix A.2 names coordinates 138, 378 and 447. The draft credits this established mechanism rather than claiming to discover it.
- [Circuit Tracing methods, attribution graphs and intervention sections](https://transformer-circuits.pub/2025/attribution-graphs/methods.html) freezes attention patterns and normalization denominators for its local linear graph and tests graph interpretations with interventions (for example its addition case study). The draft's comparison distinguishes that construction from separately executed finite gate changes without asserting priority from the difference.

No checked citation establishes that this exact study is first. The report correctly states that absence of a previous exact decomposition has not been established. The previously inaccessible residual-variance source remains an unresolved comparison; this review makes no new access or absence claim about it.
