# T18 center-by-direction factorial: prospective review

This review used source/protocol files and one existing T17 attention-snapshot shard. It loaded no model or tokenizer, selected no T18 passage, and used no GPU. It does not interpret T17 numerical outcomes. The proposed scientific arms are sound; the precisions below are required before input/helper freeze and model execution.

Reviewed proposal SHA256: `970e80a2301e74861ea1931ca4d4fddb0cc1d8bf805b39578c1b1f529877516d`.

## Scientific assessment

The 2×2 center/direction intervention distinguishes finite dependence on the fitted mean and PC1 while retaining the original eight-layer, source-value-zero boundary. The 16 scientific modes plus C/P/current/fullrank give 20 modes, 640 main condition forwards, eight anchors, 640 suffix controls and eight new calibration forwards: 1,296 total. The proposed interaction `(FF−OF)−(FO−OO)` correctly measures the center contrast at the fresh direction minus the center contrast at the original direction. Paired resampling must share each passage's index across all four cells; natural/BOS and early/later views remain correlated. One new fit gives one calibration replication, not calibration-population uncertainty. L10 and the joint layer set are development-chosen and are appropriately fixed before confirmation.

For removal at L10, the incoming state is common P, and the fresh-minus-original center shift at fixed unit vector u is `((alpha_F−alpha_O)·u)u`. The analogous orthogonal shift uses the same coefficient times v. These equalities should be checked in the implementation with the inherited numerical rules, not tested by a new outcome-chosen tolerance. Removal is invariant to the sign of u; the signed orthogonal control is not. The inherited max-absolute-coordinate sign convention is reproducible, while different basis cells also change the fixed orthogonal vector. The proposed caveat correctly prevents calling the control's basis contrast a basis-only intervention.

The lower-loss versus output-fidelity distinction and lack of mediation/unique-mechanism claims are correct. Calibration on P must be explicit. Its eight calibration metrics have a self/no-external-logit reference, not native-C KL, because no extra C calibration forwards are planned.

## Required input and geometry precision

1. Exclude **the entire new 8,192-character calibration extraction buffer** against every historical exclusion and against other newly selected calibration buffers. The original calibration helper did this. Comparing only the first512-token used span would silently weaken this calibration rule. Evaluation retains its declared used-span rule and nonoverlapping used spans within the new evaluation panel.
2. The inherited localization exclusion inventory explicitly says OLMo Wiki-test/Hume were distinct from its then-candidate sources. Its 48 transfer calibration/development buffers therefore do **not** cover all original OLMo Wiki-test/Hume exposure. The new helper must establish that missing coverage before selecting calibration passages. Existing original/tranche/continuation manifests expose these source names, starts and variable lengths; use the matching local OLMo tokenizer plus saved token arrays and source hashes to map the actual used ranges, or retain an explicit unresolved-basis failure. Do not approximate the ranges with GPT-2 offsets or assume a universal512 length. Reuse already verified Wiki-validation mapping and add T16/T17 spans, including prepared/failed panels conservatively.
3. Freeze numerical geometry failure criteria. A small but finite eigengap is an informative calibration result, not by itself a reason to replace the fit or passage panel. Reject nonfinite geometry, nonpositive total variance and a numerically unresolved leading direction using an explicit scale-aware criterion chosen before output; otherwise report eigengap and leave-one-passage-out instability without tuning. The inherited SVD reconstruction/orthogonality tolerances and QR projection threshold1e−6 remain unchanged. Fit on q1..510 only; save all calibration b/mass and the exact map/direction hashes before evaluation.
4. Bind the OO map/direction to the existing frozen original bytes. A synthetic common-input test should verify its formula equals the previous removal/control implementation, including sign and norm convention. No pretrained repetition is needed.

## Storage is not yet launch-ready

The stated128MiB normal target is below a direct tensor-content estimate for the requested evidence. An existing T17 attention state contains10,580,800 tensor bytes; nine equivalent states require95,227,200 bytes. Nine final-LN hidden arrays require14,155,776 bytes, nine sets of four full-vocabulary FP32 logit rows7,237,008 bytes, minimal main per-token loss/KL/prediction arrays6,622,560 bytes, fresh calibration b/mass3,139,584 bytes, and just four FP64 per-query diagnostics for active scientific layers37,675,008 bytes. This subtotal is164,057,136 bytes (156.46MiB), before serialization, all additional norms, source states, input copies, JSON fingerprints/operations, summaries and any failure reserve. This is a schema-based lower bound, not a complete writer benchmark; diagnostic field/dtype choices must be frozen.

A prospective normal budget near256MiB plus64MiB failure capacity may be feasible, subject to the actual writer measurement and current free space. It must not be silently substituted for128MiB. Preserve the2GiB free-space floor, pre-load projected-capacity check, per-group projected incremental checks and bounded failure recording. No model launch is approved until a complete writer/layout test includes long finite float JSON, analysis outputs and all failure classes; no earlier raw output may be removed to fit. Successful snapshot coverage is deliberately narrow, with full arrays outside that subset absent; report hash/runtime closure limits.

## Disposition

Scientific design is approved conditional on these explicit input/geometry/storage precisions. Tokenizer-only helper implementation may proceed after the parent accepts the precisions, with execution held for separate static review. No model execution or input selection is approved by this review. Independent implementation/synthetic review and a measured disk plan remain required.
