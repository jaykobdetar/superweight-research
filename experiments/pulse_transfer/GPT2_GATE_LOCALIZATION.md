The prior DuBois/Wiki sign reversal motivates these hypotheses and makes the prior panel development evidence. No layer, sign, map or rank is selected using the new panel. This screen does not fully explain rank1-retention failure. A later calibration-center by calibration-basis factorial remains a separate study.

Source V at position0 is zeroed at L4–L11 in every non-C arm, including layers whose gate is not intervened on. No recalibration occurs. Score targets2–511; early2–127/later128–511 are correlated score views of that same512 execution. No physical128 inference or claim.

## Frozen direction construction

Load the authoritative calibration_maps.pt (SHA256 ed62f089168abeec63434e5f6dfa83ff8e7e139bc362e952456ea34859b5a098), whose tensor digest is fbf127a1a618e709b0d8e39625a156f11402c9703ac4b55ae3dcfd3711571c81. For each layer, construct the following once on CPU in float64, before evaluation:

1. Let u0 be stored basis_r[:,0]. Require finite entries and abs(norm(u0)−1)≤1e−10. Define u=u0/norm(u0). This explicit normalization preserves the frozen direction/span and fixes unit-length arithmetic; it is not a refit. Keep u's original SVD sign.
2. Traverse stored basis_qr columns in increasing index0…11. For column q_j, compute w_j=q_j−u(u·q_j). Pick the first j for which norm(w_j)≥1e−6; require finite values throughout. The QR basis and its seed20261025 are unchanged. This selection uses only calibration geometry, never evaluation responses.
3. Set v=w_j/norm(w_j). Choose the smallest-index coordinate with maximal abs(v); multiply v by−1 exactly if that coordinate is negative. This fixes v's sign. Require abs(u·v)≤1e−12 and abs(norm(v)−1)≤1e−12. Fail if any condition is unmet; do not change the threshold or direction automatically.
4. Save u,v,j,residual norm,pivot/sign,FP64 diagnostic errors and shape/dtype/content hashes. The implementation will cast both u and v to the same FP32 attention dtype once, and require their norm difference and orthogonality error≤1e−6. All conditions use these same saved vectors and alpha. No per-query division by a random projection or small gate coefficient is permitted.

For each current query q≥1, define the12-head logit vector b, r=b−log(q), x=r−alpha, and s=x·u. The three gate families at an affected layer are:

- remove_pc1: b'=b−s u.
- orthogonal_control: b'=b−s v.
- position: b'=alpha+log(q).

For either directional family, evaluate its own s at its own current state. The control matches the norm of the hypothetical PC1 removal at that same state. Singleton runs have the same P trajectory entering the patched layer, so their actual prepatch states and s must be exactly equal. Joint runs develop different earlier-intervention trajectories; their actual perturbation norms need not match across runs, and no such claim or equality guard is made. Save per-query norm diagnostics of both hypothetical vectors within each run, requiring max abs(norm(su)−norm(sv))/max(1,norm(su),norm(sv))≤1e−6. Zero s naturally yields both zero vectors.

Apply sigmoid to b', preserving the current conditional non-source mixture via the already reviewed context-rescaling path. Preserve q0 relative to P. This matches logit perturbation norm, not mass/context/output norm or loss. Save those changes separately. One deterministic orthogonal direction is one control, not an ensemble or claim about all random directions.
