# Transfer tranche 1: frozen candidate and causal signatures

Predeclared before model-transfer results, 2026-10-21. This follows the reviewed OLMo case study. GPT-2 and Llama-3.2-3B-Instruct are complete, locally available checkpoints. Run them sequentially, without downloads or concurrent model loads. GPT-2 is an architecture contrast (learned LayerNorm, GELU MLP, learned positions); Llama is a modern gated MLP/RMSNorm/GQA contrast. Instruction tuning and model size are uncontrolled differences, so any difference is not attributed uniquely to architecture.

## Inputs and selection

Reuse only separately hash-identified local corpus sources; do not export copyrighted text or token IDs to the repository. Strip Gutenberg header/footer consistently before extracting passages. Development: Wiki test and Hume, four passages per source. Evaluation: Wiki validation, Du Bois, Hobbes and optimizer code, four passages each. A passage starts at floor(f*(len(text)-8192)), f in {0.1,0.3,0.5,0.7}, and contains 8192 characters. The same passages are tokenized independently for each model, without added special tokens. Use the first 512 tokens; fail if too short. Save passage hashes, starts, and complete private token tensors. These panels are new to transfer, but corpus independence is not absence from pretraining, and character locations can overlap earlier OLMo research. No cross-model token-level identity is claimed.

Select one candidate from development only: for each MLP down projection before the final decoder layer, compute mean absolute source-0 intermediate activation over eight natural-start development inputs. For each intermediate column multiply this mean by its largest absolute output weight. Choose the globally largest score (ties: layer, row, column ascending). This targets the largest typical individual contribution, not the weight with the largest absolute value. Save every layer/column score and selected output row for independent audit. GPT-2 Conv1D storage is transposed into output-by-intermediate convention for analysis only. Selection has no held-out loss criterion. Record the top ten candidates and whole-column energy fraction; lack of a large or harmful candidate remains a negative result rather than prompting a new selection rule. Seeded same-layer random row/column controls are independent of evaluation effects (three seeds 20261021..23).

## Baseline and source-0 interventions

For each of 16 evaluation passages, test 256 and512 tokens and three starts: natural, first token replaced by the tokenizer's single-token `The`, and first token replaced by its explicit BOS if defined (otherwise EOS, labeled as such). No prefix insertion, chat template, retokenization, padding, or hidden cache history. All other input IDs remain fixed; score target positions2..end to exclude direct next-token prediction at source0. Compare within each input to its own native baseline.

At the selected candidate, remove only its contribution to one output row (row deletion), or its whole down-projection column contribution (column deletion), at position0 only. Compute counterfactual output with copied weights using the native full-sequence matrix operation; never mutate parameters. Apply identical interventions to three seeded random row/column candidates. Recompute with an unmodified weight copy as an oracle; require exact per-token loss/prediction closure at one natural input of each length and corpus. Repeat native forward at these anchors. Capture source intermediate, contribution, full down output at source, and downstream source normalization summaries (RMS, max absolute coordinate, and target-coordinate fraction). Compare NLL, native-to-intervention KL, argmax agreement and per-window perplexity ratios; preserve per-token outputs privately and export numeric-only data later. Do not equate similar magnitude with causal transfer.

## Prefix-history signature

On the same frozen evaluation passages, construct U and R inputs: replace any occurrences of the tokenizer's single/double-newline IDs in positions0..128 by its single space ID; set position0=`The`, p=64 to space(U) or single newline(R), q=128 to single newline. Also test R with q=double newline. All required literals must encode to exactly one ID, otherwise mark the corresponding panel ineligible; do not substitute an unrelated tokenizer entry. Run both lengths. Measure the frozen candidate's q contribution and downstream source state, with native prediction metrics referenced within each input. This is initially descriptive localization, not a causal account of a head route.

If a substantial, reproducible prior-newline suppression appears, predeclare a separate development-only head screen and held-out K/V/Q factorial with native-recomputation oracle before inferring shared causal structure. Do not transplant OLMo's coordinate/head numbers, assume K/V head independence under GQA, or treat absence at this chosen candidate as absence of any newline mechanism.

## Uncertainty, accounting, and next decisions

Report corpus-wise paired window effects and 2000-draw bootstrap intervals (seed20261021); n=4 per corpus is small and intervals condition on frozen selection. Seeds control only random controls/bootstrap; native evaluation is deterministic with dropout disabled. Store exact checkpoint revision, file and loaded parameter hashes, all tokenizer IDs, dependency versions, dtype, native attention implementation, model configuration, code/protocol/input hashes, wall time, forward count, GPU peaks and process peak RSS. Hash model before/after and verify parameter version counters. Use BF16 for Llama and FP32 for GPT-2; this is a native-dtype comparison, not a precision-controlled architecture attribution. Stop and report an OOM; do not silently quantize/offload/change precision. No unrelated job interference.

After results, review candidate selection, closure checks, raw-summary agreement and scientific interpretation independently on CPU (<3GiB if feasible). Decide the next intervention from evidence: shared row/column damage warrants source K/V and geometry tests; shared history suppression warrants head-local causality. Negative results delimit the tested transfer signature and may motivate a different, explicitly exploratory hypothesis.

## Pre-evaluation review clarifications

All layer/row/column indices are zero-based. Intermediate activation means the post-activation input of the down projection (GELU for GPT-2, SiLU(gate)×up for Llama). Native biases remain intact. GPT-2 uses its native flattened addmm+bias operation; Llama uses F.linear. Source0 row deletion replaces only one coordinate at position0; column deletion replaces only the full position0 output. Oracle recomputation uses an unmodified copied matrix with identical shape. Selection tensors must all be finite. The frozen selection JSON and raw development tensors are hashed into the manifest before evaluation begins.

Each random control uses numpy default_rng(seed), uniformly samples row in [0,hidden_size) then column in [0,intermediate_size) in the selected layer, and aborts on an exact selected-pair collision. These are same-layer random controls, not magnitude-matched controls; the latter would address a different question. Ties in ranking use layer, row, column ascending.

History loss summaries score targets130..end (zero-based), a common unchanged suffix. The initial history comparison is exploratory localization. If it motivates follow-up, freeze the head screen and intervention protocol on development inputs, then use new nonoverlapping confirmation passages, checking actual token-to-character coverage. A promising suppression signature is at least a tenfold reduction of median absolute q contribution in R versus U in at least two corpora, with the U contribution at least 10% of the median full MLP-output norm at q; retain all measurements even if this criterion fails. Lack of this signature at the frozen candidate is not a claim that the model has no newline-dependent circuit.
