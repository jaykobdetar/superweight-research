# Llama source key/value transfer factorial

Declared after the initial transfer screen. The frozen development-selected L1/r588/c1419 has30.17% of its column energy in the largest coordinate. In initial natural512-token tests, deleting that one source0 contribution changed PPL ratios by0.5–1.9%; deleting the whole column changed them by45–69%. This differs from the OLMo single-weight case and motivates testing downstream transmission rather than assuming the same mechanism.

Use the pinned Llama-3.2-3B-Instruct checkpoint, BF16/SDPA, batch1 and512 tokens. Fresh evaluation uses the same four source fractions{.2,.4,.6,.8} as the independent GPT-2 follow-up, tokenized with Llama. Assert actual512-token character spans are disjoint from the initial Llama panel. Natural and explicit BOS starts give32 inputs. Keep the selected coordinate, all model parameters and all suffix IDs fixed; score target positions2..511. No head is selected from these outcomes.

For each input capture clean C, selected-row-deleted R and whole-column-deleted N donor worlds. Capture source0 K/V projection outputs at every layer after the selected layer (L2..27), before native RoPE. All eight KV heads are patched together; all24 query heads and GQA grouping remain native. This tests the source set, not individual head independence. K/V are fixed to same-input donor worlds. Source projections only are replaced; later-token projections remain native. Capture first downstream-layer queries and verify later queries are identical across C/R/N before transmission.

In an R recipient and separately an N recipient, test all nine combinations K from{C,R,N} and V from{C,R,N}, across all downstream layers. Full same-world K/V combinations must exactly reproduce that donor's scored losses and predictions; these are expected architectural closures, not discoveries. Mixed donors can reveal incompatibility but are conditional counterfactuals, not additive mediation proportions.

In C/R/N worlds, zero source values either with endogenous keys or with clean donor keys clamped, always across L2..27. Compare against native C for output fidelity and against each matching unmodified world for the incremental effect. Also block source0 attention for queries1..end across L2..27, preserving query0 self-attention. Because an explicit mask can change the GQA/kernel dispatch path, each world has its own explicit-causal-mask reference and source-block variant; retain native-versus-explicit-mask drift. No block-source effect is attributed to the edge alone without this matched mask reference. Do not interpret zeroing V as deleting the source from softmax.

Save exact script/protocol/input/checkpoint/dependency hashes, frozen donor tensors, per-token numeric results, input IDs privately, closures, projection-patch locality checks, uncertainty and resource accounting. No weights/corpora enter the repository. Run only after GPT-2 has exited. A later constant-source replacement requires a separate fresh calibration protocol and is not justified by low variation alone. Initial transfer panels are exploratory; this specified32-input factorial is fresh confirmation of the source-level hypothesis, not a universal model claim.
