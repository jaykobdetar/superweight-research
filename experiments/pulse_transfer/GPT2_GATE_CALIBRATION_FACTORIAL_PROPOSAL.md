## Factorial intervention and controls

For each layer, let alpha_O/u_O be the original mean/unit PC1 and alpha_F/u_F the fresh mean/unit PC1. Cross center a in {O,F} and basis d in {O,F}. Compute at that arm's own current state:

    r = b - log(q)
    s_ad = (r-alpha_a) dot u_d
    remove_ad: b' = b - s_ad u_d
    orthogonal_ad: b' = b - s_ad v_d

For each basis, construct v_d with the same reviewed deterministic QR-column projection/sign rule and thresholds as T16/T17; use the same underlying QR random matrix for both calibrations. The control matches the hypothetical removed logit-vector norm at its own state, not the context or output norm. The two norm controls use different v_d if directions differ, so a basis contrast of control effects is not a clean basis-only intervention.
